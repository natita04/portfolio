# Nati Asher Portfolio Website Replica

A pixel-perfect replica of Nati Asher's portfolio website ([natiasher.design](https://natiasher.design/)) built with Bootstrap 5 and modern web standards.

**✨ All Medium article links are fully functional and point to the actual articles on UX Collective and Bootcamp publications.**

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Bootstrap 5**: Utilizes the latest Bootstrap framework for clean, modern styling
- **Accessibility**: ARIA attributes and semantic HTML for screen readers
- **Performance Optimized**: Minimal custom CSS, leveraging Bootstrap utilities
- **Modern Typography**: Uses Inter font for clean, professional appearance
- **Interactive Elements**: Hover effects and smooth transitions

## Technologies Used

- **HTML5**: Semantic markup structure
- **Bootstrap 5.3.2**: CSS framework for responsive design

- **Custom CSS**: Fine-tuned styling to match original design
